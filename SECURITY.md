# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability in Shannon.ai, please email security@example.com instead of using the issue tracker.

Please include:
1. Description of the vulnerability
2. Steps to reproduce
3. Potential impact
4. Suggested fix (if any)

We will acknowledge receipt within 48 hours and provide an estimated timeline for a fix.

## Security Best Practices

When using Shannon.ai:

1. **Only scan authorized targets** - Always obtain explicit written permission
2. **Keep dependencies updated** - Regularly update security packages
3. **Use HTTPS** - Connect to HTTPS endpoints when possible
4. **Secure credentials** - Never commit API keys or tokens
5. **Review results carefully** - Validate all findings before acting
6. **Report responsibly** - Follow responsible disclosure practices
7. **Use in secure environments** - Run in isolated networks for testing
8. **Monitor logs** - Track and review all scanning activities

## Responsible Disclosure

We follow responsible disclosure principles:
- We will acknowledge your report promptly
- We will work to fix the issue quickly
- We will credit you (if desired) in the release notes
- We will not disclose details until a fix is released
